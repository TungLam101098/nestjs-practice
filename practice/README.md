## OVERVIEW

- This document describes the practice with the objectives, technical stacks and task lists to show the achievement from Node.js training.

## TIMELINE:

- 6 days

## TARGET:

- Understand about diagrams and implement them: use case, sequence, ERD.
- How to build database flow the diagrams is drawn before.
- How to define APIs document for application.
- Apply single and middleware pattern to project.
- How to build Node.js application using express framework.
- How the application connects and interacts with the database.
- Apply unit test for application with coverage 90%.

## APP REQUIREMENTS

- Registration
- Login
- Handle token to verify
- Get courses from course list
- Add course to course list and wishlist list
- Update course from course list
- Delete course from course list and wishlist list

## TECHNICAL STACKS

- Mongodb version 4.4
- Express version 4.18.2
- Mongoose version 7.4.3

## SYSTEM REQUIREMENTS

- Node version 14
- Docker version 1.41
